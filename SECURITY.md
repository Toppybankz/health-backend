# Security Policy

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Use GitHub's private vulnerability reporting feature for this repository when available, or contact the repository owner privately.

## Scope

This is a portfolio project and is not approved for handling real patient or other sensitive health information. A dependency scan and automated checks do not constitute a full security assessment.

## Supported versions

Only the current default branch and actively maintained pull requests are considered for security fixes.
